# Approved template history

Every version of the campaign book template that has been approved is kept
here as a frozen snapshot, so any earlier look can be restored.

Each snapshot is a folder named `vN-YYYY-MM-DD/` holding the class file and
its two assets (`apotheosis-book.cls`, `apo-paper.jpg`,
`apo-footerscroll.pdf`) plus the preview PDF it was approved from.

Only approved versions go here. Work in progress lives one level up.
