# Supplementary material

Extras that go with the campaign but are not part of the book. Everything in this folder is published with the website (GitHub Pages serves `docs/`), so the site can load it directly while the table plays online.

| Folder | What it holds |
| :-- | :-- |
| [`cards/`](cards/) | Item and spell cards, shown in the website interface during play. |

New kinds of material (maps, handouts and so on) get their own folder here.
