# Class emblem sources

Six class emblems are flat traces (one-colour silhouette) of reference art Charl supplied and has
permission to use (2026-11-04). The reference images are not stored in the repo.

| Class | Source |
| --- | --- |
| Blood Hunter | Arathaka, tattoo flash (thorned eye) |
| Warlock | tentacle-and-eye emblem supplied by Charl |
| Mystic | spiral-eye star emblem supplied by Charl |
| Carlislean Lycanthrope | hands-and-wolf illustration supplied by Charl |
| Artificer | gear-in-triangle emblem supplied by Charl |
| Sorcerer | flame-hand sketch supplied by Charl |

The other class emblems are traced from Baldur's Gate 3 class art (Larian Studios), as fan content.
